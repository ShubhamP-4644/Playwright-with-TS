# Source Code vs Byte Code vs Binary Code

## Example file

`CHAPTER_01_BASICS/01_HelloWorld.js`
```js
console.log("Welcome to JS World");
```

## Comparison

| Aspect | Source Code | Byte Code | Binary Code (Machine Code) |
|---|---|---|---|
| Definition | Human-readable code written by a developer in a programming language | An intermediate, platform-independent representation generated from source code | The lowest-level code made of 0s and 1s that the CPU directly executes |
| Example (for `01_HelloWorld.js`) | `console.log("Welcome to JS World");` | V8's internal Ignition bytecode instructions generated after parsing the JS (not human-readable, e.g. opcodes like `LdaConstant`, `CallProperty`) | The actual x86/ARM machine instructions the CPU runs after V8's TurboFan JIT-compiles the hot bytecode |
| Who reads/writes it | Written and read by developers | Generated and consumed by a virtual machine/interpreter (e.g. V8, JVM) | Generated by a compiler/JIT and executed directly by the CPU hardware |
| Readability | Fully human-readable | Not human-readable; a structured intermediate format | Not human-readable; raw binary instructions |
| Platform dependency | Platform-independent | Platform-independent (runs on any machine with the matching VM) | Platform/CPU-architecture dependent |
| Execution | Cannot run directly; must be parsed/compiled first | Executed by a virtual machine (interpreted or JIT-compiled) | Executed directly by the CPU |
| File extension example | `.js`, `.java`, `.py` | `.class` (JVM), V8 internal bytecode (no file, kept in memory) | `.exe`, `.dll`, `.so`, or CPU instructions in memory |
| In this JS example | `01_HelloWorld.js` as written | When Node.js/V8 parses this file, it compiles it into V8 bytecode first | V8's JIT compiler (TurboFan) further compiles hot bytecode into native machine code for the CPU to execute |

## Flow for `01_HelloWorld.js` in Node.js (V8 engine)

```
Source Code (01_HelloWorld.js)
        │  parsed by V8
        ▼
Byte Code (V8 Ignition bytecode)
        │  JIT-compiled by V8 TurboFan (for hot code)
        ▼
Binary/Machine Code (native CPU instructions)
        │  executed by
        ▼
        CPU
```
