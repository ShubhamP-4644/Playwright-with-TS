# VS Code Commands / Shortcuts — Mac

## General

| Action | Shortcut |
|---|---|
| Command Palette | Cmd+Shift+P |
| Quick Open (go to file) | Cmd+P |
| Go to Symbol in file | Cmd+Shift+O |
| Go to Symbol in workspace | Cmd+T |
| Go to Line | Ctrl+G |
| New Window | Cmd+Shift+N |
| Close Window | Cmd+Shift+W |
| Settings | Cmd+, |
| Keyboard Shortcuts | Cmd+K Cmd+S |
| Zoom In / Out | Cmd+= / Cmd+- |
| Toggle Full Screen | Ctrl+Cmd+F |

| Action | Shortcut |

| Close All Editors | Cmd+K Cmd+W |
